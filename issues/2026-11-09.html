Level Up

Multi-factor authentication protects personal data a password alone cannot

Multi-factor authentication, also called two-factor authentication, grants access only after the user presents two or more distinct types of evidence. The method protects personal identification and financial assets from an unauthorized party that may have discovered a single password. A study of Microsoft Azure Active Directory users found that MFA reduced the risk of compromise by 99.22% across the entire population and by 98.56% in cases of leaked credentials, that over 99.99% of MFA-enabled accounts remained secure, and that dedicated MFA applications such as Microsoft Authenticator outperformed SMS-based authentication.

Sources: wikipedia.org · arxiv.org

Password managers keep unique passwords in an encrypted vault

A password manager stores usernames and passwords in an encrypted vault whose encryption key is commonly derived from a master password chosen by the user. Most password managers can generate passwords, save credentials as they are entered, and fill them when the user returns, reducing reuse of the same password across accounts. Some can also synchronize records between devices and store payment-card details, notes, and documents. Password management software has been around since the 1990s in desktop and browser-based forms.

Today's field: AI & machine learning

  • Attention. In machine learning, attention is a method that determines the importance of, or attends to, each component in a sequence relative to the other components in that sequence. In natural language processing, that importance is represented by weights assigned to each word in a sentence. Attention encodes vectors called token embeddings across a fixed-width sequence that can range from tens to millions of tokens in size. The attention mechanism was introduced as an idea inspired by the human visual system and has been applied to a variety of tasks. [wikipedia.org · springer.com]
  • Reinforcement learning from human feedback. Reinforcement learning from human feedback, or RLHF, is a technique to align an intelligent agent with human preferences. The method trains a reward model to represent those preferences, then uses that model to train other models through reinforcement learning. In classical reinforcement learning, an agent learns a policy, a function that guides its behavior, and that function is iteratively optimized to increase the reward signal derived from the agent's task performance. RLHF seeks to train the reward model directly from human feedback, including ranking data collected from human annotators. [wikipedia.org · arxiv.org]
  • Embedding. In machine learning, embedding is a representation learning technique that maps complex, high-dimensional data into a lower-dimensional vector space of numerical vectors. The same term also denotes the resulting representation, where meaningful patterns or relationships are preserved. The technique learns these vectors from data like words, images, or user interactions, differing from manually designed methods such as one-hot encoding. Similar concepts may be mapped to nearby vectors, including word embeddings for text such as Word2Vec. [wikipedia.org · arxiv.org]
